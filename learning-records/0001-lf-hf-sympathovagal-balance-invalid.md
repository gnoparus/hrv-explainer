# Prior knowledge: LF/HF-as-sympathovagal-balance is invalid

User opened this workspace already knowing the headline claim — "LF/HF is
not a valid sympatho-vagal balance index" — and named the primary source
(Billman 2013) unprompted. Depth claimed is citation-level, not
mechanism-level: the user knows the conclusion and the source, but the first
lesson (`lessons/0001-spectral-hrv-pitfalls.html`) still needed to cover the
*why* (mixed LF origin, non-linear PNS/SNS interaction, respiratory
confound) since that wasn't demonstrated.

This also matters for the app: `hrvployyy` (PRODUCT.md, README.md,
`MetricsStrip.tsx`) already encodes this correctly — the LF/HF invalidity is
a stated product argument, not something to fix in the app. Future lessons
in this workspace can build on "LF/HF is invalid" as known ground and skip
re-establishing it; the open floor is the *mechanistic* explanation and
adjacent contested metrics (VLF, ULF).
