## Design Context

Register: **product** (single-screen instrument, not a marketing surface).

- `PRODUCT.md` — users, purpose, brand personality ("clinical, precise, alive"), anti-references, accessibility requirements.
- `DESIGN.md` + `.impeccable/design.json` — the visual system (colors, typography, components) extracted from `src/index.css` and `src/components/`.

Read both before making UI changes; `/impeccable` commands read them automatically.
